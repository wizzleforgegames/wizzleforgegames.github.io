Who we are

What we build

  • HTML5/Canvas browser and mobile games
  • One codebase for all platforms: VK Play, Yandex Games, RuStore
  • Ads and purchases inside the game, no pay-to-win
  • Fast updates: a new build ships in a day

How we test

  • Every game is tested on phone and desktop
  • Ads, purchases, leaderboards and achievements are checked
  • We audit UI overflow on every screen size
  • Bugs are fixed before moderation

Player rules

  • Games start instantly, no sign-up
  • Ads never interrupt a round
  • Purchases are cosmetics and "no ads" only
  • Progress is stored on the device
